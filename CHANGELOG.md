## [0.1.0] - 2026-11-18

### Added
- Editor toolbar button that opens or focuses the Antigravity panel, wherever it lives (left or right side bar).
- `Agy Button: Open Agy Panel` command (`agyButton.open`) in the command palette.
- Clear error message when the Antigravity extension is not installed or enabled.
- Extension icon and toolbar button icons for light and dark themes.
- Support for untrusted workspaces (the extension never runs workspace code).
